# Plugin Skills Graph

Renders an interactive graph of Claude skills as a Paperclip dashboard tab.

- **Sidebar:** "Skills Graph" entry under the workspace nav.
- **Page route:** `/<companyPrefix>/skills-graph` , full-bleed iframe with the inlined Canvas renderer.
- **Renderer:** adapted from [RUBRIC Skill Trees](https://github.com/robonuggets/rubric) (Canvas force-directed, MIT-with-attribution license , the "Created by RoboLabs" badge must remain visible).
- **Data:** structurally honest cross-references built by [graphify](https://github.com/conradnomura/graphify). Communities (Louvain) drive the cluster layout.
- **Agents:** toggleable overlay maps each skill to one or more sub-agents (Alex, Peter, Tony, Vale, Nemo, Atlas, Marly, Martin, Pei-Ling, Emil, Chef, Hunter) using a keyword routing table baked into the build script.
- **Search:** top-right input filters/highlights skills by name or description.

## Development

```bash
pnpm install
pnpm dev            # watch builds
pnpm test
pnpm typecheck
pnpm build
```

## Regenerate the graph data

The graph HTML + data are generated by `scripts/build-graph-html.py` from graphify output:

```bash
python3 scripts/build-graph-html.py
pnpm build
```

This reads `<workspace>/graphify-out/skills_graph.json` and `.graphify_labels.json`, then writes `src/ui/graph-html.ts` (which is inlined into the UI bundle and rendered inside an iframe `srcDoc`).

Override the graphify location with `GRAPHIFY_OUT=/path/to/graphify-out`.

## Install Into Paperclip

Plugin install requires board-scoped auth. Use the Plugin Manager UI to install from a local path:

```
/home/USER/paperclip/packages/plugins/examples/plugin-skills-graph
```

After reinstalling, the sidebar entry and page route appear automatically.

## Adjusting the agent routing table

The routing table lives in `scripts/build-graph-html.py` (`AGENTS = [...]`). Each agent has a list of keywords; matching is done with word-boundary checks against each skill's folder name, label, and description. To re-tune assignments, edit the keyword lists, re-run the generator, and rebuild.
